# 📱 CadastroClientesApp

Aplicativo Android para cadastro de clientes, desenvolvido como parte de um projeto acadêmico. O foco é proporcionar uma interface simples e eficiente para entrada de dados com validações básicas.

---

## ✨ Funcionalidades

- Cadastro de Nome Completo
- Campo de E-mail com validação
- Seleção de Sexo com RadioButtons (Feminino, Masculino, Outro)
- Seleção de Escolaridade com Spinner (Fundamental, Médio, Superior, Outros)
- Validações de campos obrigatórios com mensagens de erro
- Feedback em tempo real via Toast
- Interface adaptável e preparada para futuras expansões

---

## 🛠️ Tecnologias Utilizadas

- Java
- Android Studio
- ConstraintLayout
- EditText, RadioGroup, Spinner, Button, Toast
- Validação com `android.util.Patterns`
